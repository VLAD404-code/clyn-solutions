Official website for **C-LYN SOLUTIONS LIMITED** (Kitwe, Zambia).

Mining & automotive truck parts, heavy duty equipment, electrical spares and general trading.

**Slogan:** Your solution, is our Resolution.

## Live site

After deploying on Vercel, your URL will look like:

`https://your-project-name.vercel.app`

## Admin

- URL: `/admin` or `/admin.html`
- Default password: `clyn2026` (change this after first login if you hardcode a new one in `data.js`)

## Local development

Open `index.html` in a browser, or:

```bash
npx serve .
```

## Stack

Static HTML / CSS / JS. Product data stored in the browser (localStorage) via the admin panel. Use **Backup** in admin regularly.
